# Frontend GitHub Pages — Versión 2.0.0

Publica el contenido de esta carpeta como raíz de GitHub Pages.

Antes de publicar, edita únicamente `config.js`:

- `API_URL`: URL `/exec` del despliegue de Apps Script.

No añadas Client ID, API keys, PIN ni secretos. Para conservar la actualización PWA segura, publica `version.json` al final.
